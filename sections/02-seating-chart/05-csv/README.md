# 名簿の CSV からまとめて作る

座席表セクションの 5 つめ（最後）。名簿の CSV を読み込んで、クラスごとの座席表をまとめて PNG にする回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。
「ファイルを選択」で `example/names.csv` を選ぶと、3 クラス分の座席表が並びます。

## 前の節からの差分

- `main.js` から `TITLE` / `NAMES` を消し、`<input type="file">` で CSV を読む
- CSV は UTF-8 で読めなければ Shift_JIS で読み直す（Excel で普通に保存した CSV 対策）
- クラスごとに canvas を作って並べ、「まとめて PNG で保存」で 1 枚ずつ間をあけてダウンロード
- 席より人が多いクラスは、足りない人数を画面に出す
- `names.csv` … 練習用の名簿（架空の 70 人・3 クラス）。配布 ZIP に入る

## 講師向けメモ

- プロンプトに名簿が 1 人も入っていないことを必ず指摘する。「形だけ伝えて、中身は手元で入れる」
- 複数ファイルのダウンロードはブラウザが確認してくる。「許可」を押せずに 1 枚しか保存されない
  受講者が出るので、アドレスバー右端のブロック表示を案内する
- 時間が余った人には「使えない席や机の並びを言葉で変えてから、もう一度 CSV を読み込む」を勧める。
  部屋の設定（コード）と名簿（ファイル）が分かれている良さが分かる
