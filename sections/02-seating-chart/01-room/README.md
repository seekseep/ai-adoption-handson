# 部屋とテーブルを描く

座席表セクションの 1 つめ。部屋と丸テーブルを言葉で伝えて、上から見た図を PNG で保存できるページを作る回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。サーバーは要りません。

## 完成例の中身

```text
01-room/
├── LECTURE.md        教材本文（docs: true → サイトに載る）
├── README.md         このファイル
├── images/           説明図の SVG（_build.py で genfig から生成）
└── example/          完成例（配布 ZIP とライブプレビューの元）
    ├── index.html    画面の骨組み（canvas と保存ボタン）
    ├── main.js       部屋とテーブルの設定・図を描く・PNG で保存
    └── style.css     見た目
```

配布 ZIP を解凍すると `seating-chart/` フォルダができます。次の節以降も同じ名前なので、
上書き展開していけば同じフォルダが育っていきます。

## 講師向けメモ

- 狙いは「**言葉で伝えたことが、プログラムの中の数字になる**」を体験すること。
  「言葉で変えてみる」で Codex に「main.js のどこを変えましたか？」と聞かせるところが山場
- 入力欄を作らないのは意図的。設定を変える手段は Codex への言葉だけ、にしておく
- 背景を白で塗らないと PNG が透明になり、Windows のフォトで黒く見えることがある。
  受講者の画像が黒いときはこれ
- `file://` で開くことを最初に体に入れてもらう。後半の「通信していない」の伏線になる
