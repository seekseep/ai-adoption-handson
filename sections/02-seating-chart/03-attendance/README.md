# 出席情報を反映する

座席表セクションの 3 つめ。「今日いる人だけを席に割り当てる」回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。

## 完成例の中身

```text
03-attendance/
├── LECTURE.md
├── README.md
├── images/
└── example/
    ├── index.html    マップ ＋ 席の情報 ＋ 出席の3欄
    ├── main.js       出席者を空き席へ順に割り当てる
    └── style.css     割り当てた席・欠席の席の見た目
```

## 講師向けメモ

- ここで初めて**アプリが判断をする**（誰をどこに座らせるか）。前 2 節は表示だけだった
- 「固定席の人が欠席ならその席は空ける」という仕様は、受講者から出てこないことが多い。
  出てこなければ講師から投げて「仕様の抜けはこうやって見つかる」と見せる材料にする
- 席が足りないケースを必ず試させる（出席を増やす）。エラーではなく業務上の問題として
  画面に出すべき、という話につなげる
