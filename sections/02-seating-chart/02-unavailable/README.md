# 使えない席を指定する

座席表セクションの 2 つめ。「この机は使えない」を言葉で伝えて、図の上で描き分ける回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。

## 前の節からの差分

- `main.js` に `UNAVAILABLE`（使えない席の一覧）を追加
- 使えない机は灰色＋×、椅子なし。図の下に凡例

## 講師向けメモ

- 「場所を言葉で指すのは長いし、読み違えも起きる」を体感させて、次の節の番号につなぐ
- Codex が違う机を塞ぐのはよくある。それ自体を「言い方を具体的にする」練習にしてよい
- 凡例が画面（HTML）側に出て、保存した PNG に入らないパターンが多い。確認ポイントで拾う
