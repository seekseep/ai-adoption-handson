# 固定席・使用しない席などの情報を入れる

座席表セクションの 2 つめ。前の節の画面に「席ごとの事情」を足す回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。

## 完成例の中身

```text
02-fixed-seats/
├── LECTURE.md
├── README.md
├── images/
└── example/
    ├── index.html    マップの欄 ＋ 席の情報の欄
    ├── main.js       席の情報を読んで色分けする
    └── style.css     固定席・使用しない席の見た目
```

前の節（01-layout）からの差分は「席の情報」欄の追加と、それに応じた色分けだけです。

## 講師向けメモ

- ここで教えたいのは**データを 1 つの欄に詰め込まない**こと。配置と事情は別のデータ
- 「マップに `A1!田中` のように書けばいいのでは」と聞かれたら、後で条件が増えたときに
  読めなくなる例を出して説明する
