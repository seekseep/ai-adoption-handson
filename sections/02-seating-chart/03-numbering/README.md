# 席に番号を振る

座席表セクションの 3 つめ。使える席に、ルールに従って番号を振る回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。

## 前の節からの差分

- `main.js` に `numberSeats()` を追加。前の列から、同じ列は左から数え、使えない席は飛ばす
- 番号は描くたびに数え直す（決め打ちで持たない）

## 講師向けメモ

- 伝えたいのは「**値を書き込むのではなく、ルールを書いてもらう**」。
  プロンプトの「決め打ちで書かずに、描くたびに数える」がそれ
- 「言葉で変えてみる」で使えない席を増やし、番号が自動で詰まるのを見せる。
  決め打ちで書かれていた受講者はここで番号がずれるので、それも教材になる
