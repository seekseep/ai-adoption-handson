# 席に名前を入れる

座席表セクションの 4 つめ。名簿の順に、番号の席へ名前を入れる回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。

## 前の節からの差分

- `main.js` に `TITLE`（見出し）と `NAMES`（名簿）を追加
- 名前の入った席は番号を左上に小さく、名前を真ん中に。長い名前は文字を縮めて収める
- 保存ファイル名を見出しと同じにする

## 講師向けメモ

- 後半の「この作り方の困ったところ」が本題。**名簿を丸ごと Codex に渡している**ことに気づかせる。
  ここは 03-security への伏線なので、深追いせず「後でやります」で止める
- 名簿はすべて架空。受講者が実名を打ち込もうとしたら止める
