# 座席の配置図を作る

座席表セクションの 1 つめ。Codex に初めて「画面のあるもの」を作ってもらう回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。サーバーは要りません。

## 完成例の中身

```text
01-layout/
├── LECTURE.md        教材本文（docs: true → サイトに載る）
├── README.md         このファイル
├── images/           説明図の SVG
└── example/          完成例（配布 ZIP とライブプレビューの元）
    ├── index.html    画面の骨組み
    ├── main.js       マップの文字を読んで机を並べる
    └── style.css     見た目
```

配布 ZIP を解凍すると `seating-chart/` フォルダができます。次の節以降も同じ名前なので、
上書き展開していけば同じフォルダが育っていきます。

## 講師向けメモ

- ここでの狙いは**作りきることではなく、Codex が画面を作れると知ること**
- 受講者ごとに見た目が違うのが正常。「完成例と同じ」を目指させない
- `file://` で開くことを最初に体に入れてもらう。ここが後半の「通信していない」の伏線になる
