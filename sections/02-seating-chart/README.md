# 座席表を作る

最初の実習です。**座席表を作る画面**を Codex に作ってもらいます。

題材が座席表なのは、「条件が後からどんどん増える」仕事の代表だからです。
最初はただの表なのに、固定席が出てきて、使えない席が出てきて、欠席者が出てきて、
「あの 2 人は離してほしい」と言われる。この増え方を Codex 相手に体験するのが目的です。

## このセクションでやること

4 ステップで、同じ 1 つの画面を育てていきます。

| | ステップ | 増える条件 |
|---|---|---|
| 1 | [座席の配置図を作る](./01-layout/LECTURE.md) | まず机を並べる |
| 2 | [固定席・使用しない席を入れる](./02-fixed-seats/LECTURE.md) | 動かせない席がある |
| 3 | [出席情報を反映する](./03-attendance/LECTURE.md) | 来る人と来ない人がいる |
| 4 | [条件を伝えながら修正する](./04-refine/LECTURE.md) | 「あの 2 人は離して」 |

## 進め方

各ステップは同じ形をしています。

1. **Codex に投げるプロンプト**が書いてあるので、コピーして自分の Codex に貼る
2. 出てきた `index.html` をダブルクリックしてブラウザで開く
3. **確認ポイント**を見て、できていれば次へ
4. うまくいかなければ、ページ末尾の**完成例**を見る

:::notice[出てくるものは毎回違います]
Codex は同じ指示でも毎回まったく同じコードを書くわけではありません。色や配置が違っていても、
確認ポイントを満たしていれば正解です。「完成例と同じにする」ことを目標にしないでください。
:::

## 使うデータ

架空の部署の座席データを使います。実在の人名は出てきません。
