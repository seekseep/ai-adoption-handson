# 座席表を作る

最初の実習です。**部屋の座席表を画像（PNG）で作るページ**を Codex に作ってもらいます。

部屋の大きさも、丸テーブルの並べ方も、どの席が使えないかも、**すべて言葉で伝えます。**
Codex はそれをプログラムにします。変えたいときも、また言葉で頼みます。
最後は、名簿の CSV を渡すだけで、クラスごとの座席表が一気に画像になるところまで持っていきます。

## このセクションでやること

5 ステップで、同じ 1 つのページを育てていきます。

| | ステップ | できるようになること |
|---|---|---|
| 1 | [部屋とテーブルを描く](./01-room/LECTURE.md) | 部屋とテーブルを言葉で伝えて、図を PNG で保存する |
| 2 | [使えない席を指定する](./02-unavailable/LECTURE.md) | 座れない椅子を塞ぐ |
| 3 | [席に番号を振る](./03-numbering/LECTURE.md) | 「17 番の席」と 1 語で指せる |
| 4 | [席に名前を入れる](./04-names/LECTURE.md) | 名簿の順に人を座らせる |
| 5 | [名簿の CSV からまとめて作る](./05-csv/LECTURE.md) | CSV 1 つで、全クラス分の画像を一気に保存する |

できあがりはこうなります。名簿の CSV を 1 つ選ぶと、クラスごとの座席表がまとめて画像で保存されます。

![名簿の CSV から保存された、A・B・C クラスの座席表の PNG 画像 3 枚](./05-csv/images/result.png)

## 進め方

各ステップは同じ形をしています。

1. **Codex に投げるプロンプト**が書いてあるので、コピーして自分の Codex に貼る
2. ブラウザで `index.html` を開く（2 回目からは再読み込み）
3. **確認ポイント**を見る
4. **言葉で変えてみる**で、Codex に変更を頼んでみる
5. うまくいかなければ、ページ末尾の**完成例**を見る

:::notice[出てくるものは毎回違います]
Codex は同じ指示でも毎回まったく同じコードを書くわけではありません。色や線が違っていても、
確認ポイントを満たしていれば正解です。「完成例と同じにする」ことを目標にしないでください。
:::

## 使うデータ

架空の新人研修（A・B・C の 3 クラス、70 人）の名簿を使います。実在の人名は出てきません。

[セキュリティの話](../03-security/README.md) で扱います。まずは気楽に触ってください。
