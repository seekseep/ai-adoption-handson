# 学習されない設定

セキュリティセクションの 3 つめ。「学習されない」と「送られない」は別だという話。

動くサンプルは無い。設定手順と、2 つの違いの図。

## 事実の出どころ

- 個人プラン: 設定 → データ制御 →「Improve the model for everyone」をオフ
- 個人プランの Codex タスクにも同じ設定が効く
- Codex には別に「Include environments」という設定がある（ChatGPT 側の設定では変わらない）
- Business / Enterprise / Edu / API は**既定で学習に使われない**

手順やスイッチ名は変わることがある。当日の朝に実機で確認すること。

## 講師向けメモ

- ここが一番誤解が多い。**「オフにした＝送っていない」ではない**を必ず持ち帰らせる
- 受講者がその場で設定できるので、実際にやってもらうと定着する
- 会社アカウントの人は既定でオフなので、「自分は関係ない」で終わらせず
  「それでも送信はしている」に話をつなぐ
