# AI エージェントに与える権限

セキュリティセクションの 4 つめ（最後）。「どこまで任せるか」を自分で決める回。

## デモ

`demos/scope/index.html` … 権限モードを切り替えると、Codex が何にどこまで手を出せるかが
変わる様子を表で見せるデモ。実際の Codex を動かしているわけではなく、挙動を図示しているだけ。

## 権限モード（2026 年 9 月時点）

| 表示名 | 作業フォルダの中 | フォルダの外 / ネットワーク |
|---|---|---|
| Ask for approval（既定） | 自由 | 止まって確認 |
| Approve for me（設定上は Auto-review） | 自由 | 自動チェックを通して進む |
| Full access | 自由 | 制限なし・確認なし |

後ろ 2 つは、設定 → General → Permissions で有効化しないとメニューに出ない。
モードを有効にしても選択されるわけではない。

## 講師向けメモ

- ここは**脅す回ではなく、操作を覚える回**。実際に権限メニューを開いてもらう
- Full access を「使うな」ではなく「いつ使うか・使うときに何をするか」で教える
- 作業フォルダを分ける習慣（顧客データのあるフォルダを指定しない）が最大の防御。
  ここだけは持ち帰らせる
