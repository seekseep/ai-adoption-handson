# セキュリティの話

手を動かす時間から離れて、座って聞く時間です。

座席表を作ってみて、「思ったより何でもできるな」と感じたと思います。**その「何でもできる」が
そのままリスクでもある**という話をします。

## このセクションでやること

| | 話すこと | 問い |
|---|---|---|
| 1 | [AI エージェントってなに？](./01-what-is-agent/LECTURE.md) | ChatGPT と何が違うのか |
| 2 | [外に出してはいけないデータ](./02-data-to-protect/LECTURE.md) | 何を渡してはいけないのか |
| 3 | [学習されない設定](./03-training-optout/LECTURE.md) | 設定すれば安全なのか |
| 4 | [AI エージェントに与える権限](./04-permissions/LECTURE.md) | どこまで任せるのか |

## このセクションの結論を先に

3 つだけ持ち帰ってください。

1. **Codex に渡した文字は、OpenAI のサーバーに送られる。** これは設定では変わりません。
   変えられるのは「送ったデータを学習に使うか」だけです
2. **だから「渡さずに済ませる」方法を覚えるのが一番効く。** その具体的なやり方が
   [データと仕組み](../04-data-and-logic/README.md) と
   [シフト表を作る](../05-shift-table/README.md) の中身です
3. **AI エージェントはファイルを消したりプログラムを動かしたりできる。** どこまで任せるかは
   自分で決められるし、決めるべきです

## 前提

このセクションの内容は「一般的な注意点」です。**最終的には自分の組織のルールに従ってください。**
会社が禁止していることは、技術的に可能でもやってはいけません。
