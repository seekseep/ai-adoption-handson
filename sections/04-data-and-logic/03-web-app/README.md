# 仕組みを Web アプリケーションにする

「データと仕組み」セクションの 3 つめ。仕組みを「誰でも使える形」にする回。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。

## 完成例の中身

```text
03-web-app/
├── LECTURE.md
├── README.md
├── images/
└── example/
    ├── index.html    入力・処理・出力の3パネル
    ├── main.js       集計の手順（各ステップを画面に出しながら進む）
    └── style.css     見た目
```

交通費の明細を貼ると、日付ごとに集計して CSV で保存できる。
**処理のパネルに手順を出す**のがこの完成例の肝で、「中で何が起きているか」を
見せるために入れてある。

## 講師向けメモ

- ここで教えたいのは**アプリの作り方ではなく、入力/処理/出力という見方**
- 自分の業務を「入力は何か、出力は何か」で言い直す練習をさせると、06 の題材選びが速くなる
- CSV 保存が通信なしでできることに驚く人がいる。04-web-tech への橋渡しに使う
