# Web 技術ってなに？

「データと仕組み」セクションの 4 つめ（最後）。ブラウザで何ができるのかを 4 つのデモで見せる回。

## デモ

| デモ | 見せるもの |
|---|---|
| `demos/screen/` | HTML だけで画面の部品ができること（JS なし） |
| `demos/calc/` | 計算がその場で反映されること |
| `demos/draw/` | 図をその場で描いていること（画像ではない） |
| `demos/file/` | 人が選んだファイルを読み、加工して保存し直せること |

`file` デモは `<input type="file">` と Blob のダウンロードを使うので `file://` でも動く。

## 講師向けメモ

- ここは**安心してもらう回**。「ホームページの技術でこんなことができるのか」という驚きを取る
- `file` デモの「ブラウザは勝手にフォルダを見に行けない」は、01-setup/02-python の
  伏線回収になっている
- 「インストール不要でファイルを渡すだけで配れる」は、社内展開を考える人に刺さる
