# 仕組みからデータを作る

「データと仕組み」セクションの 2 つめ。このハンズオン全体の中核。

## デモ

`demos/rule/index.html` … 条件（人数・日数・1 日あたりの人数）だけを入力すると当番表が
生まれるデモ。入力がデータではなく条件であることを体で分からせるためのもの。

## 講師向けメモ

- ここが一番大事な回。**「入力がデータ」→「入力が条件」の切り替え**が伝われば今日は成功
- 「AI にプログラムを書いてもらう」という話に聞こえると身構える人がいる。
  「プログラム」ではなく「仕組み」「手順書」と言い換えると入りやすい
- 損益分岐の話（何回繰り返すなら仕組み化するか）を入れておくと、現実的な判断ができる
