# データと仕組み

このセクションが、このハンズオン全体のいちばん大事な考え方です。

座席表の 4 つめでは、名簿を Codex に**渡して**、名前入りの座席表を作ってもらいました。
でもそれだと、名簿が変わるたびに渡し直すことになり、そのたびに社外に情報が出ていきます。
5 つめで CSV を手元で読む形に変えたのは、実はこのためです。ここでは、その発想を正面から扱います。

> **データを渡して答えをもらう** のではなく、**答えを作る仕組みをもらう**。

仕組みを一度もらってしまえば、あとは自分の PC の中でデータを流し込むだけです。
データはどこにも出ていきません。
