# 使う道具

このハンズオンで使うのは、**Codex アプリ**・**ブラウザ**・**フォルダ（エクスプローラー）**の 3 つだけです。
コマンドを打つ場面はありません。

## Codex アプリ

Codex は「チャット画面から指示を出すと、指定したフォルダの中にファイルを作ってくれるアプリ」です。
画面で覚えておくのは 3 か所だけです。

| 場所 | 何をするところか |
|---|---|
| **フォルダの表示** | いま Codex がどのフォルダで作業しているか。ここ以外は勝手に触りません |
| **入力欄** | やってほしいことを日本語で書くところ |
| **入力欄の下の権限メニュー** | Codex にどこまで任せるかを切り替えるところ |

3 つめの権限メニューは [AI エージェントに与える権限](./03-security/04-permissions/LECTURE.md) で
詳しく扱います。当日は最初から触らなくて大丈夫です。

## ブラウザ

作ったツールはすべてブラウザで動きます。**Edge** か **Chrome** を使ってください。

### ファイルをブラウザで開く

作られた `index.html` を**ダブルクリック**すると、そのままブラウザで開きます。
インターネットには一切つながっていません。自分の PC の中だけで動いています。

アドレスバーを見ると `https://...` ではなく `file:///C:/Users/...` のように
なっているはずです。これが「自分の PC のファイルを開いている」という印です。

### 開発者ツール（Network タブ）

[データの行き先を確認する](./05-shift-table/04-data-flow/LECTURE.md) で 1 回だけ使います。
`F12` キーを押すと画面の横か下に開きます。**Network** タブを選ぶと、そのページが
どこかに通信したかどうかが一覧で見えます。

何も出てこなければ「どこにもデータを送っていない」ということです。そこを自分の目で
確かめるのが、このハンズオンのひとつの山場です。

## フォルダ（エクスプローラー）

Codex が作ったファイルを確認したり、ZIP を解凍したりするのに使います。

### 拡張子を表示しておく

Windows は初期設定でファイルの種類（`.html` や `.js`）が隠れています。**表示されるように
変えておいてください。** 隠れていると「index が 2 つある」のように見えて混乱します。

エクスプローラーを開き、**表示 → 表示 → ファイル名拡張子** にチェックを入れます。

Mac の場合は Finder の **設定 → 詳細 → すべてのファイル名拡張子を表示**です。

## テキストエディタ（任意）

Codex が書いたコードを自分で少し直したくなったとき用です。**メモ帳でも足ります。**

もう少し読みやすくしたい人は [Visual Studio Code](https://code.visualstudio.com/) を入れて
おくと、色分けされて見やすくなります。当日必須ではありません。

:::notice
このハンズオンのコードは、サイト上の「このステップの完成例」パネルでも読めます。
手元にエディタが無くても進められます。
:::
