# 環境構築

Codex を自分の PC で動かせる状態にします。**必須なのは最初の 1 つだけ**で、あとの 2 つは
「必要になったら読む」参考ページです。

## このセクションでやること

| | やること | 必須か |
|---|---|---|
| 1 | [Codex をインストールする](./01-codex-app/LECTURE.md) | **必須** |
| 2 | [Python をインストールする](./02-python/LECTURE.md) | 参考 |
| 3 | [Node.js をインストールする](./03-nodejs/LECTURE.md) | 参考 |

## なぜ Python と Node.js が「参考」なのか

このハンズオンで作るツールは、**HTML ファイルをダブルクリックすればブラウザで動く**ものだけです。
動かすための追加のソフトは要りません。

Python や Node.js は「プログラムを動かすための土台」で、本来こういうツールを作るときには
必要になることが多いものです。ただ今回は土台が要らない作り方を選んでいるので、
入れなくても最後まで進めます。

参考ページを用意したのは、次の 2 つの場面のためです。

- **Python** — ブラウザだけでは足りず、フォルダの中のファイルを直接読むツールを作りたくなったとき
- **Node.js** — Codex をアプリではなく**ターミナルから**使いたくなったとき（Codex CLI）

どちらも今日の本編では使いません。興味があれば休憩時間に読んでください。
