# データを渡さない仕組みを作る

シフト表セクションの 3 つめ。4 通りの解き方の 3 番目（仕組みだけもらう）。ここが本命。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。

## 完成例の中身

```text
03-local-logic/
├── LECTURE.md
├── README.md
├── images/
└── example/
    ├── index.html    勤務できる曜日 ＋ 条件 の2入力、シフト表 ＋ 確認 の出力
    ├── main.js       勤務日数の少ない人から選ぶ方式。連勤・上限を見る
    └── style.css     見た目
```

**このアプリは一切通信しない。** CDN も読み込まない。次の 04-data-flow で
DevTools の Network タブを開いて検証するので、外部読み込みを足さないこと。

配布 ZIP を解凍すると `shift-table/` フォルダができる。

## 講師向けメモ

- ここでの体験の芯は「**実データを 1 文字も渡していないのに、いちばん良い結果が出る**」
- 受講者が作るものは完成例と違ってよい。確認ポイントだけ満たせばよい
- 作ったあと必ず「実データを入れてみてください」と言う。ここで初めて本物が入る。
  そのうえで 04 で通信が無いことを確認する、という順番が効く
