## 当日の注意

サイトに埋め込んだプレビューは「サイトを表示するための通信」があるので、検証には
**手元の index.html をダブルクリックで開いたもの**を使わせること。
ここを取り違えると「通信してるじゃないか」となる。

## 講師向けメモ

- ここは**信じさせる回ではなく、確かめさせる回**。講師が言い切るのではなく手を動かさせる
- F12 で画面が変わると戸惑う人が出る。「元に戻すのは同じ F12」を先に言っておく
- 比較対象として、通信するページ（適当なニュースサイト等）を 1 つ開かせると差が鮮明になる
- 最後の「では Codex 自体は？」の整理を飛ばさないこと。ツールは通信しないが、
  Codex とのやりとりは通信している
