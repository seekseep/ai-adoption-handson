# 実際に小さなツールを作ってみる

応用セクションの 4 つめ。40 分の制作時間。

## 動かす

`example/index.html` をダブルクリックすればブラウザで開きます。

## 完成例の中身

```text
04-build/
├── LECTURE.md
├── README.md
├── images/
└── example/          ひな形（題材を問わず使える骨組み）
    ├── index.html    入力2欄 ＋ 処理の表示 ＋ 出力の表 ＋ CSV保存
    ├── main.js       process() だけを書き換えれば別の業務に使える形
    └── style.css     見た目
```

ひな形の `process()` の上下にコメントで区切りを入れてあり、
「ここだけ書き換えてもらう」と Codex に頼めるようにしてある。
配布 ZIP を解凍すると `app/` フォルダができる。

## 講師向けメモ

- **完成させなくてよい**を繰り返す。40 分で業務ツールは完成しない
- ゼロから頼む人と、ひな形から始める人の両方を許す。後者の方が速い
- 進まない人には「処理を 1 段階にまで削る」よう促す
- 残り 10 分で必ず手を止めさせ、動く／動かないに関わらず 05-qa に入る
