# 自分の業務に応用する

最後の時間です。ここまでは用意された題材でしたが、ここからは**自分の仕事**を題材にします。

座席表とシフト表で使ったやり方は、そのまま他の作業にも効きます。
「毎月やっている面倒な手作業」を 1 つ選んで、小さく作ってみましょう。

## このセクションでやること

| | やること | 目安 |
|---|---|---|
| 1 | [面倒な作業を探す](./01-find-tasks/LECTURE.md) | 10 分 |
| 2 | [Codex に相談しながら考える](./02-design-with-codex/LECTURE.md) | 10 分 |
| 3 | [題材カタログ](./03-examples/LECTURE.md) | 5 分（迷ったら見る） |
| 4 | [小さなツールを作ってみる](./04-build/LECTURE.md) | 40 分 |
| 5 | [質疑応答と持ち帰り](./05-qa/LECTURE.md) | 残り時間 |

## 大事なこと

**完成させなくていいです。** 40 分で業務ツールは完成しません。ここでの目的は
「自分の仕事で Codex が効くかどうかの感触をつかむ」ことです。

途中まででも、「あ、これいけるな」か「これは無理だな」が分かれば成功です。
無理だと分かることにも同じくらい価値があります。

## 題材選びのコツ

いい題材には共通点があります。

- **毎月・毎週やっている** — 一度作れば何度も効く
- **手順が決まっている** — 「その時々で判断」が多いものは向かない
- **入力と出力がはっきりしている** — 「この表から、この表を作る」の形
- **データを渡さずに済む** — 仕組みだけ作ればいい形にできる

迷ったら [題材カタログ](./03-examples/LECTURE.md) から近いものを選んでください。
